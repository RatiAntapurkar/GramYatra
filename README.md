GramYatra is a web-based platform designed to promote rural tourism by connecting travelers with village experiences, local culture, and stays.

## How to Clone the Repository
clone the repo 

cd GramYatra
cd frontend
npm install
cd ..
cd backend
npm install
cd ..
cd admin
npm install
cd ..

## Add .env with the help of .env.example also add mongodb url in backend/config/db.js

## To Start the Project
cd backend
npm run server
## split terminal
cd frontend 
npm run dev
## split terminal
